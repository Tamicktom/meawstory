# 2D-1 · Exibir o resumo de progresso

**Fase 2 · Etapa D — Progresso** · Tipo: Implementação · [Card pai](../00-card-pai.md)

## Objetivo
Mostrar a prática realizada sem ranking nem punição por ausência.

## Escopo
- Contar cenas criadas e revisões enviadas.
- Contar palavras escritas com regra definida para evitar duplicar versões copiadas.
- Apresentar os números em uma tela de Progresso.
- Não usar ranking, medalhas ou sequência de dias.

## Critérios de conclusão
- Os totais são reproduzíveis a partir do histórico e distinguem escrita inicial de revisão.

## Dependências
- [1G-1 · Criar uma revisão e guardar as versões](../fase-1-revisao/1G-1-criar-revisao-e-guardar-versoes.md)
