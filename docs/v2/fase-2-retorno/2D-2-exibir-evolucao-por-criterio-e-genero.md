# 2D-2 · Exibir evolução por critério dentro de cada gênero

**Fase 2 · Etapa D — Progresso** · Tipo: Implementação · [Card pai](../00-card-pai.md)

## Objetivo
Mostrar evolução sem misturar rubricas incompatíveis.

## Escopo
- Agrupar o progresso por gênero.
- Mostrar evolução por critério ao longo das leituras estruturadas.
- Usar faixas como informação principal e pontuação como apoio.
- Não calcular média geral entre critérios de gêneros diferentes.
- Excluir leituras antigas sem dados estruturados.

## Critérios de conclusão
- Cada série apresentada compara somente o mesmo critério dentro de uma rubrica compatível.
