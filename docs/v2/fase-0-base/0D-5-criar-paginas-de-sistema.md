# 0D-5 · Criar páginas de carregamento, erro e não encontrado

**Fase 0 · Etapa D — Português, celular e páginas de sistema** · Tipo: Implementação · [Card pai](../00-card-pai.md)

## Objetivo
Substituir respostas genéricas por estados próprios que orientem a próxima ação.

## Escopo
- Criar estados de carregamento compatíveis com cada fluxo.
- Criar página de rota inexistente com link para o Início.
- Criar página de erro inesperado com opção de tentar novamente.
- Informar, quando couber, que o texto salvo não foi afetado.
- Não exibir códigos de erro ou IDs internos.

## Critérios de conclusão
- Carregamento, rota inexistente e erro inesperado têm apresentação própria e uma saída clara.
