# 0C-3 · Iniciar o editor vazio e manter apenas parágrafos

**Fase 0 · Etapa C — Ciclo atual confiável** · Tipo: Implementação · [Card pai](../00-card-pai.md)

## Objetivo
Evitar o envio acidental de conteúdo de exemplo e não prometer formatação que se perde.

## Escopo
- Remover “Hello World!” do conteúdo inicial.
- Usar “Comece no meio da cena.” como convite não editável.
- Manter parágrafos no editor e no texto enviado.
- Remover ou desabilitar controles e atalhos de formatação que não sobrevivem ao envio.

## Critérios de conclusão
- Uma cena nova começa sem texto real no editor.
- Parágrafos são preservados do envio até a exibição da cena.
