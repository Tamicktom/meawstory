## Objetivo
Substituir o texto do template por instruções e contexto reais do Meawstory.

## Escopo
- Explicar a proposta de treino de cenas, leitura e revisão.

- Remover instruções herdadas que não se aplicam ao projeto.

## Critérios de conclusão
- Uma pessoa desenvolvedora consegue entender e executar o projeto usando somente o README e as referências indicadas.
