# 0C-1 · Transformar a lista de textos em Minhas cenas

**Fase 0 · Etapa C — Ciclo atual confiável** · Tipo: Implementação · [Card pai](../00-card-pai.md)

## Objetivo
Dar um lugar real para reencontrar a cena, já que as mensagens de espera e de falha apontam para Minhas cenas desde esta fase.

## Escopo
- Apresentar a lista atual, em `/dashboard/texts`, como Minhas cenas na interface e na navegação.
- Listar cada cena uma única vez, com exercício, data e situação.
- Levar cada item à tela adequada ao estado da cena.
- Mostrar um estado vazio com caminho para os exercícios.
- Deixar versões, faixas e filtros para 2B-3.

## Critérios de conclusão
- Toda cena da pessoa aparece uma única vez na lista.
- Uma cena em espera, com falha ou com leitura pronta pode ser reaberta a partir da lista.
