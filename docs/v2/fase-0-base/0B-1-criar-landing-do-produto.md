# 0B-1 · Criar a landing do produto

**Fase 0 · Etapa B — Entrada e conta** · Tipo: Implementação · [Card pai](../00-card-pai.md)

## Objetivo
Substituir o template da home por uma entrada clara para o ciclo de escrita e revisão.

## Escopo
- Usar a mensagem “Escreva uma cena. Receba uma leitura honesta. Reescreva melhor.”
- Mostrar um trecho curto de cena e uma leitura real como exemplo.
- Explicar o processo em três passos: escrever, ler e revisar.
- Declarar que a IA não escreve pela pessoa e que o texto continua sendo dela.
- Oferecer as ações “Escrever minha primeira cena” e “Já tenho conta”.

## Critérios de conclusão
- A home não contém mais o template inicial.
- As duas ações levam aos fluxos corretos de cadastro e login.
